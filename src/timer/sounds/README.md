# Sounds

Put the two sound files of the application here:

- `work_end.<ext>` — the end of a work interval;
- `break_end.<ext>` — the end of a break.

`<ext>` is `wav`, `ogg`, `flac` or `mp3` (`mp3` needs `ffplay`). Without a file there is no sound.
